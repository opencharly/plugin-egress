### Schema

```cue
#KindCluster: {
	kind:       "Cluster"
	apiVersion: =~"^kind\\.x-k8s\\.io/"
	nodes: [#KindClusterNode, ...#KindClusterNode]
	...
}
#KindClusterNode: {role: "control-plane" | "worker", ...}
```

Open beyond the envelope (kind's Cluster spec varies), structured at the envelope
— the real egress failure mode (a missing/empty `kind`/`apiVersion`, an empty
node list, a node with an invalid role).
